# 出口质量历史

出口常驻被动记录近期网络表现，供卡顿后按时间回看。`homeway serve quality` 只读本机历史，不启动 daemon、不访问手机、不发起测速。出口升级到包含本功能的 Release 后才开始采集，升级前的时间无法补采。

2026-10-23 本机 Mac 已部署官方 v0.3.20，历史从 00:13:37（+08:00）开始；阿里云本轮未升级，仍为 v0.3.19，尚无本功能。部署与回退凭据见 `DEPLOY-RUST-EXIT.md` §13.18。

## 查询

```sh
homeway serve quality
homeway serve quality --since 30m
homeway serve quality --from '2026-10-22T20:10:00+08:00' --to '2026-10-22T20:20:00+08:00'
homeway serve quality --since 10m --device 0123456789abcdef
homeway serve quality --since 10m --json
```

默认最近 10 分钟。`--since` 接正时长，如 `30s`、`10m`、`1h`，与 `--from/--to` 互斥。`--from` 单给时终点是现在，`--to` 单给时查询其前 10 分钟。起止也可给 Unix 毫秒；日期必须明确时区，范围为 `[from,to)`。

设备使用报告列出的完整 **16 位十六进制 devTag**，不是日志里的 8 位短指纹。同设备新旧连接分世代差分。过境流在认证入站时固定设备归属，未知单列，不在关闭时根据 IP 猜归属。

Mac 在本机执行；其他出口升级到 v0.3.20 或更新版本后，登录目标主机执行同形命令。默认 state 为 `~/.config/homeway`，正式实例不需要 `--state`；该参数仅用于私有实例和临时测试。

## 读数口径

| 位置 | 观测 | 能回答什么 |
|---|---|---|
| 手机 ↔ 出口 | RTT、直连/中继、QUIC 发送包/判丢/拥塞、收发字节、发送缓冲丢弃与占用 | 隧道同期是否有延迟抬升、判丢、拥塞或中继路径 |
| 出口内部 | 转发处理耗时、整形积压、上下游队列与背压、采样间距 | 数据在哪个队列等待，处理是否出现长拍；背压本身不证明处理器或网络故障 |
| 出口 ↔ 目标 | IP/端口、TCP 建连耗时/失败、实际 socket 收发字节、首上游字节等待、平台支持的 TCP RTT/重传 | 是否只有特定目标方向连接慢或传输异常 |

- RTT 的 P50/P95 来自**周期快照的 RTT 估计值**，不是逐包 RTT 分布。
- QUIC 判丢为出口发送方向的协议估计，ACK 回程也影响观测，不能解释为手机上行或双向应用丢包率。判丢可能滞后于发送，窗口比值只作估计。
- 目标 TCP RTT 来自出口系统 socket；原生 TCP 重传包/字节按平台能力分别输出。不支持为不可用，不能据此宣称无重传。
- 首上游字节等待从首次实际向 upstream 写有效载荷开始，到首次后续读到有效载荷结束；服务端先发数据时无可比起点。它是**连接级**观测，可能包含 TLS/协议交互、网络与远端处理，不是 HTTP TTFB。
- 加密与多路复用连接无法拆出每个业务请求。UDP `connect` 成功只是本地 socket 就绪，无回包不直接算请求失败。DNS 进程内流与普通过境流分开，不将内部代答记为远端 TCP 拨号。
- 吞吐是实际传输，**不是链路容量**。应用空闲、服务端慢、窗口约束、客户端读取慢都可能低速。App 到主机测速走服务流，可辅助对照，不能替代 DATAGRAM/L3 应用数据面的结论。

## 历史与覆盖

- 路径和活跃流每 5 秒采样；短流关闭时保留摘要。流量按窗增量，建连/首字节按生命周期去重，不把长流累计字节重复加入每窗。
- 转发线程只向 4 槽有界通道非阻塞提交；独立写者序列化与落盘。结束流摘要队列 4096、结束 QUIC 连接队列 256，满时显式计丢弃。
- 路径首次样本只建基线，计数回退或路径变化重新分段。首次采样前的隧道字节不能完整归窗，短 QUIC 会话可能只有结束快照；过境流摘要仍能提供真实 socket 字节。
- `<state>/cache/quality/quality.jsonl` 与 `.1`–`.3` 每份最多 8 MiB，总上限 32 MiB。按容量淘汰，**不承诺固定保留时长**。Unix 目录 0700、文件 0600；只记录 IP/端口及指标，不记录正文、URL 或 token。
- 查询只计完整落入范围的增量窗；跨边界不按比例推算，报告列出排除的边界窗。范围小于采样粒度时可能无可归窗流量，应扩大范围。
- 报告显示覆盖起止、重启、采样缺口、损坏/半尾、队列丢失与写盘错误。持续磁盘错误还通过 `quality: 历史写入失败` 节流记日志；后续写盘恢复再落计数。正常停机最多等待200ms排空，超时与线程异常有明确日志；崩溃或超时末尾可能未落盘。并发轮转或追加时标注覆盖不完整/近似快照，必要时重查；坏行计数覆盖现存文件，无法精确归属某个设备或时间段。
- **无数据、缺样、低流量都不能判为健康。** 报告给保守线索；出口单侧指标不能精确分解双向损失和业务等待。当前未采进程 CPU、手机调度和手机上行发送端判丢。

## 验证

```sh
cargo test -p homeway-core quality
cargo test -p homeway-quic quality
cargo test -p homeway-cli quality_cli
tools/quality-e2e.sh 94
```

脚本使用 `tools/local-rust-exit.sh` 的私有实例，两设备经真实 QUIC DATAGRAM、TUN socketpair、TCP 拦截重拨访问本机 echo，核对长短连接字节、同目标设备隔离和报告，退出自动停私有实例。它不替代真机现场验收。
