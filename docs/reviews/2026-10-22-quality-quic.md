# 出口 QUIC 质量采样专项评审（2026-10-22）

## 技术设计（开工前）

- 范围：仅出口已认证绑定的被动观测，不改线协议、准入/恢复节拍、线程模型或拥塞控制；纯 std DTO 暴露给引擎低频采样。
- 归属：绑定的 devTag、双地址和单调连接编号为身份；Quinn UDP 与 path 计数按当前锁定版本实现均为连接累计，RTT/cwnd/缓冲占用是瞬时值。丢包仅指出口发送端判丢；并非双向丢包。
- 路径：真实远端与出口腿表（含最近摘腿保护窗）确定 direct/relay，不能凭地址猜测；地址或承载变化增加观测 epoch。快速往返迁移可能落在两次观测之间，报告明确采样局限。
- 并发：先在绑定锁内克隆少量句柄，锁外读 Quinn stats；最终样本也先摘绑定再读取，避免绑定锁→Quinn 锁倒序。地址在读 stats 前后不稳定则重试，仍不稳定跳过该次采样。
- 生命周期：替换、按连接摘除、按公钥摘除、收工清表均保留一次最终 DTO；最终队列有界（256 条），溢出丢最旧并提供累计覆盖缺口。队列只存 DTO，不延长 Connection/socket 环生命周期。
- 缓冲：1 MiB DATAGRAM 总量减实际空余量为占用，分别记本连接 DATAGRAM 预检缓冲满及桥出站队列满；socket/注入共享面丢弃不强行归属某设备。
- 风险与验证：真实双设备绑定隔离、未认证连接不入样、同设备重连新编号/旧连接最终记录、路径迁移 epoch、stop 后最终记录与释放端口、队列覆盖边界。

## 第一道门：结构化技术自评

reviewer skill 当前限定用户显式评审调用，本任务按 ROADMAP 后备渠道做结构化自评。

- 对齐完整性：采样在现有出口边界上旁路读取，原判据行和协议不变。
- 边界/错误面：空绑定为空；短连接最终队列兜底；溢出公开计数而非假定全覆盖。
- 并发/资源：不增加线程；Quinn 句柄只在短暂锁外采样期间保留，最终队列无句柄。
- 基线漂移：不改变策略常量；采样 epoch 仅代表已观测的路径状态，累计数不能当路径独立累计。
- Rust 结构：DTO/enum 承担边界；复用既有 Arc/Mutex 绑定表，不新增独立连接注册表。

结论：可实施；必须在代码评审中复核所有摘绑定路径以及缓冲计数归属。

## 第二道门：代码结构化自评（完工后）

评审角色独立按摘绑、重连、发送失败、迁移与收工路径反向检查。

- **中：已整改**——满队列投递先克隆绑定后计数会与摘绑最终快照竞争，可能使最后一次失败不入最终样本。改为绑定锁内执行有界拷贝、非阻塞 try_send 与归属计数；日志锁外，未引入连接锁。
- **中：已整改**——巡检若在取得质量状态锁前读取旧 remote，可能覆盖并发周期采样已观测的新地址。改为先锁该绑定质量状态，再读取真实路径。
- **低：已整改**——新增腿表判定方法插到旧方法文档注释中间，已拆开，两个方法分别有明确口径。
- 身份/重连：活动样本只来自已认证 by_dev 绑定，不把全局计数摊到设备；同设备重连使用原有单调连接号，新/旧计数不混合；协议刷新不调用 bind，因此不重置绑定观测起点。
- 生命周期/资源：连接结束、替换、按公钥撤销及 clear 均入最终队列；后续 sweep 不重复记录；队列仅持 DTO，stop/panic 的 socket 释放回归通过。
- 路径/错误面：地址与实际发送路由前后读取一致才标 path_stable，最多三次重试；持续迁移仍留下连接累计数据，path_stable=false 提醒消费端跳过路径归因。快速往返迁移、未观测旧路径末尾以及摘绑后的关闭收尾包不承诺覆盖。
- 计数定义：核实锁定 quinn-proto 0.11.19 源码 Connection::stats 与路径迁移实现，sent/lost/congestion 为 self.stats 中连接累计，RTT/cwnd 为当前路径仪表；消费侧跨 epoch 应重设路径归因基线。服务流、ACK 与握手均包含在承载计数中，无法声称是应用正文吞吐。
- 缓冲范围：归属明确的 DATAGRAM 预检满/桥出站队列满合计到该连接；中继 socket、注入队列及共享入站队列不强行归属。退役连接计数只到摘绑最后读取时刻。
- Go 直译痕迹：无字符串错误、新线程、额外协议注册表或逐包分配观测事件；仅复用绑定句柄与每绑定质量状态，纯 std DTO 保持异步边界。

结论：无未处置高/中风险项。低频被动采样存在天然覆盖限制，已在 DTO 与接口文档中明确；最终队列溢出由 quality_finished_overflow 公开。
