### 2.2 flake 口径（设计 §9.2 五条）落地情况

1. **不钉固定端口**：岛内一切回环端点 `bind("127.0.0.1:0")` + 读回；harness 同样全 `:0`（连
   「固定端口」字样都无）✓
2. **时间断言禁精确墙钟**：只判上界（`elapsed < 预算 × 4` = 8s）与「预算内收工」形态；用例 5a/5b
   **不设墙钟下界**（只判「回执不挂死 + 记行到达 + 返回值形态」）✓
   ——**但设计 §9.2-2① 的「`tokio::time` + `start_paused`」机制未落地、也未加 tokio dev-dependency
   `["test-util"]`**：M0 骨架**没有纯定时语义用例**（唯一时间面是「真实线程 + 有界等待」），引
   `test-util` 会构成「声明了不用」。M1 引入纯定时用例时**同批**加 dev-dependency + 暂停时钟形态
   （已登记为交接项）。
3. **不依赖 loadavg**：岛内零吞吐断言（性能判据全在 harness）✓
4. **隔离复跑纪律**：本轮实测到两次整包失败（见 §5.2），均为 `daemon::tests::*` 时序族在
   「整包并行 + 环境争用」下的 flake，与改动面无交集 ⇒ 按仓内口径**不与本批混判**（隔离复跑与
   模块级复跑均绿）。
5. **登记动作**：五条文本**待主会话插入** `docs/QUIC-ROADMAP.md`「已知 flake 登记」节（本棒按主会话
   指令不动路线文件）——可直接粘贴的文本见 §7。
