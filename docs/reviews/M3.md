## 2. S5 准入失败归因回传（§4）

### 2.1 出口关闭码表与落点

- **码表单源** = `crates/homeway-quic/src/admit_close.rs`（新增，纯 std）：
  `0x11 凭证不被接受` / `0x12 资源暂不可用（稍后重试）` / `0x13 准入数据非法` / `0x14 准入超时`。
- **带码点**（准入窗内三处，§4 的「4 + 3」表）：`exit/conn.rs::reject()`（MAC 不符/证明失败闸
  ⇒ `0x11`；引擎裁决按桶；帧格式/版本族 ⇒ `0x13`）、`time_out()`（两族计时器 ⇒ `0x14`）、
  `ask_engine` 入境队列满（⇒ `0x12`）；**准入后**的会话级关闭（`unbind_pub` 的 `device removed`、
  `bind` 的 replaced）与刷新面拒绝留 `0`（`CloseCode::Session`）。
- **引擎裁决的类**跨 crate 带回：`RejectWhy::EngineRejected` 由单元变体改为携带
  `EngineRejectClass{Credential,Resource}`；映射单源 =
  `homeway-core::server::table::RejectReason::engine_class()`
  （`no-token`/`revoked` ⇒ 凭证桶；`table-full`/`ip-conflict` ⇒ 资源桶）。
- **出口侧详细归因行（`quic: 准入被拒（dev=…`）与计数集逐字不变**（§4 的安全面：不发新帧、
  不改状态机、不放宽任何闸）。

### 2.2 客户端映射与观测面

- `IslandErr::AdmissionRejected{code}`（**只在未绑定态**映射；白名单外/无关闭原因仍
  `RegistrationFailed`）与 `IslandErr::SessionClosed{reason}`（准入后的独立分支）——分界写死
  在 `client/register.rs::{admission_rejected, session_closed}` 一处（设计门 F4）。

  `quic: 准入被拒（` 区分）；准入后关闭单记 `quic: 会话被对端关闭（%s）——会话级归因（非准入面）`。

## 3. 偏离设计（逐条 + 原因）

1. **QUIC 档连接面失败不注入 WG 恢复阶梯**（设计 §1.6 写「只有 `{Closed,Timeout,EngineGone}`
   触发恢复」）。**原因**：§3.4 明令「QUIC 档不再产生 C11 族行」，而现有 `run.recover_until`
   的动作面全在 WG（`rebase/rearm/reset_peer_session`）——QUIC 档调它 = 既产生 C11 族行又做无效
   动作。**本切片取**：连接面失败在调用方预算内**重试一次**（`dial_with`），QUIC 档的恢复动作
   整体归 S4 的阶梯重写。**影响面**：QUIC 档服务流拨号的失败路径（可观测面 = 既有 C19 族行 +
   新增 `quic: 服务流重试（tag=%s；首试 %s；余预算内再试一次）`）。
2. **§5.1 第 5/6 项（`files.rs:207`、`service_exec.rs:577`）在 M3 不适用**。**事实**：
   `files.rs` 的动词面只被 CLI 本地形态消费（`homeway-cli` 的 files 命令 + `Session` 拨号
   = WG 承载）；`service_exec.rs` 是「服务会话」域（`ClientCoreServiceStart` 自陈
   「App 进程内、无 TUN 的 WG 会话 + 三座桥」）——**该域没有岛**（岛的构造点 = 隧道域，§2.6）。
   App 核的服务流实际走**隧道域**的桥，已换轨（§1.2 的 `[e2e5]`）。**影响面**：设计 §5.1 表的
   第 5/6 行需 S6/S7 按此订正（不是漏做）。
3. **`quic` 段存在判据放宽**：从「quic 档 **且 L3 落在岛上**」改为「quic 档 **且岛已构造**」。
   **原因**：岛建连失败（含准入被拒）时本世代回落 WG——旧判据下该段整段缺席，§4 要求的
   「App 可见为什么走了 WG」不可达（M2 真机发现①的黑洞面）。**影响面**：`tunStatusJSON` 读者
   （additive 键 + 段落出现面变化）⇒ S7 登记。
4. **A13 的 `facade/term_op.rs` 文案不改**（「出口 7724 端口上不是终端服务」）：它是 Go 真源
   （`baseline:app_term.go:125`）的 App 可见文本，改字会脱钩基础词表；且该处端口是「服务身份」
   指代而非拨号目标。代码内已写明登记（如需去端口 = 跨仓词表批）。
5. **QUIC 档未知虚拟端口 ⇒ `Unsupported` 错**（不回落 WG）：静默回落会把「QUIC 档零 stackb」
   变成条件成立；三个服务端口全在映射内 ⇒ 生产面不可达。
