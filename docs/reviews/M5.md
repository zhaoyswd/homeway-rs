**额外闭合（本项必需，非顺手改 relay 其它面）**：双栈监听下**回包族适配**。
`relay/mod.rs` 原先 9 处「发给客户端/后端」的出口一律 `udp.send_to(buf, 对端)`，但对端地址在收包处已按 Go
`readLoop` 同义 `unmap` 成**纯 v4**；监听 socket 变 AF_INET6 后，Linux/OHOS 上「AF_INET6 socket + `sockaddr_in`
的 msg_name」= `EAFNOSUPPORT`（macOS 宽松 ⇒ **本机 e2e 看不出差异、真机才炸**）。故新增单点收口：

```rust
fn send_peer(&self, udp: &UdpSocket, buf: &[u8], dst: SocketAddr) -> io::Result<usize> {
    udp.send_to(buf, crate::udpbatch::xmit_addr(dst, self.listen_v6))   // 族适配复用既有 xmit_addr
}
```
`grep -n "udp\.send_to" crates/homeway-core/src/relay/mod.rs` = **仅 `send_peer` 体内 1 处**（9 处出口全部改道）。
`listen_v6` 在 `run` 里由**绑定事实**定一次（`matches!(udp.local_addr()?, SocketAddr::V6(_))`）——单栈 v4 监听恒 false
（`xmit_addr` 原样返回，行为与改前逐字节相同）。

## 4. S7c 读数（Q8：`reactor_turn → poll(0)` 每拍固定税复测，**只测不改**）

> 口径照设计 §6-Q8②：出口 **32 连接稳态**下的每拍成本 + 空兴趣集（`n_fds == 0`）短路证据；
> 交付物 = **读数 + 处置结论**（不是代码改动）。`server/intercept/**` 本棒 **零 diff**（`git diff --stat b96cd96..HEAD -- crates/homeway-core/src/server/intercept/` 为空）。

### 4.1 结构化事实（短路点在不在）

`crates/homeway-core/src/server/intercept/mod.rs:2241-2243`：
```rust
let n_fds = self.pollfds.len();
if n_fds > 0 {                                   // ← 空兴趣集短路（:2242）
    let rc = unsafe { libc::poll(self.pollfds.as_mut_ptr(), n_fds as libc::nfds_t, 0) };
```
⇒ 无流（`pollfds` 空）时**不进 `poll`**：每拍只剩「Vec clear + 空表迭代 + 剂量计数」≈ 亚微秒，**零系统调用**。

### 4.2 实测（本机私有出口 + 客户端统一进程 + 32 条 SOCKS 慢读流，经隧道打到 firehose；`tools/local-rust-exit.sh` 同款私有实例、state/端口独立）

**同机微基准（判据来源，`clang -O2` 现场编译；32 个真实 fd 混合 POLLIN/POLLOUT，10 万次一轮）**

| nfds | 1 | 8 | 32 | 64 |
|---|---|---|---|---|
| 每次 `poll(0)` | 0.63 µs | 2.02 µs | **7.06 µs** | 14.48 µs |

⇒ 近似 O(N) 线性（32 fd 已是微秒级）。**每拍固定税（32 流）= 174–228 拍/s × 7.06 µs ≈ 1.2–1.6 ms/s = 0.12–0.16% 核**。

### 4.3 结论（处置 = **不改**，理由与成本）

1. **空兴趣集 = 零税（实测 + 结构）**：`n_fds==0` 短路 ⇒ 无系统调用；空载整进程 CPU 0.93% 核，其中 reactor 面
   贡献 = 亚微秒级扫描（<0.01% 核）——设计预期「空兴趣集零税」**成立**。
2. **有流时 = O(N) 小税**：32 流稳态每拍 ≈ **7 µs 级**（`poll(0)` 系统调用，微基准同口径实测）；
   折算 **0.12–0.16% 核**（拍频 174–228/s）。`单拍峰` 91–2473 µs 是**调度停顿**（Q-It 已同口径标注「非本批靶点」），
   不是每拍的稳定成本。
3. **`sample` 的 wall 占比（reactor_turn 5.29%）不可当 CPU 读**：同窗线程级 CPU 只有 1.83% 核（驱动线程总计），
   故 reactor 的真实 CPU 量级 ≲1% 核——**以 4.2 的「拍频 × 微基准」为准（0.12–0.16% 核）**，`sample` 只用于
   **相对归因**（reactor 的 97.6% 花在 poll 系统调用帧、扫描/分发只占 2.4%）。
4. **不改的三条理由**：①F2（兴趣集并入引擎唯一 poll）已被 Q-It 实测**负收益**并整条回退（拍频 13.2k→21.4k/s、
   CPU +14.5%、up 吞吐 −5.9%）⇒ 按设计 §6-Q8①**不重做**；②消除本税的形态只能是「兴趣集增量维护」这类
   **结构性改动**，收益 ≈0.1% 核——**成本/收益比不成立**；③当前税不构成任何门槛风险（远低于 Q-It 止损闸门 20%）。
5. **归 M6 的口径**：设计 §6-Q8③的触发条件（「实测每拍成本仍显著」）**未成立** ⇒ 不立项；若 M6 仍要做，
   须先用 CPU 口径（`sample`/`perf` 的 on-CPU 采样，而非 wall 占比）复测，并先解决 Q-It 的「拍频放大」面。

## 6. 偏离设计 + 原因（逐条）

1. **S7a 的 R1 形态只变「任意地址」面，显式 IP 不放宽**（设计 §8.5-L-9 的「从/到」字面读起来像连 `127.0.0.1` 也变 `[::]`）——
   取 **Go `favoriteAddrFamily` 语义**（显式 IP 按族单栈）；理由与影响见 §2.3。影响面小、就地解决 + 登记（R1 草案按此写）。
2. **S7a 连带改「回包族适配」**（新增 `Relay::send_peer` + 9 处出口改道）——**不是顺手改**：双栈监听下不做映射，
   Linux/OHOS 上 v4 回包直接 `EAFNOSUPPORT`（macOS 掩盖）。设计 §6-Q2 未点名，但它是 ② 的必要闭合（否则「v4 老路无回退」当场不成立）。
3. **S7a 附带改 `tools/local-rust-relay.sh`**（新增 `RELAY_LISTEN`/`RELAY_ADVERTISE` 覆盖；缺省=原回环形态）——
   设计把该脚本列为本项**影响面**（§8.5-L-9）；不改它则无法用同一私有 harness 出 v6 读数。缺省形态零变（隔离语义不变）。
4. **S7b/Q3 取「告警 + 本轮照常公布」**（Go 是「告警 + `return false` 本轮不公布」）——设计 §6-Q3 给的字面形态即此
   （未写早退），理由 = 公告/token 是产品面，不该被 L3 缓存写不进去改写。残余差异已登记（§3.2）。
5. **S7b/Q5 比 Go 严一点**：拒**端口 0**（Go `netip.ParseAddrPort` 收 0）——按设计 §6-Q5 括注「端口 1–65535」。已登记（§3.2）。
6. **S7b/Q5 的「守护期告警清空」按设计「倾向同批做」落了**（设计留的是「差异登记或同批做」二选一）：落在 `ServeEngine::start`
   开头（Go `fill()` 同位）；正常 CLI 形态恒不触发（flag 面 fail-fast / config 面拒启）⇒ 只是第二道防线 + 与 Go 同形。
7. **S7c 结论与设计预期一致、处置 = 不改**（设计 §6-Q8③ 的「归 M6」触发条件未成立）：读数与理由见 §4。
8. **S7a 补充一个 v6 数据面用例**（`forward_fallback_session_end_to_end_over_v6`）随收口 commit 落——同一 S7a 切片、**无生产代码改动**；
   理由：设计 §11-S7a 的完成判据要求「v6 客户端经中继可用」，而全链 v6 在 island 面不可达（§5.4/§7-1），故把 relay 面的数据面证据补足。

## 7. 偏离设计 + 原因（逐条）

1. **语义面三条的落点（登记面，非偏离）**：①`SessionSnapshot::stats` 在宿主会话 = 岛**服务流**字节

   ⇒ `Err(HostErr::Start)`；**暖机硬失败**（建连后探活报无连接面）⇒ `Ok(session)` + `state=failed`
   （与 WG 档 `Session::start` 的 Ok-but-failed 语义逐条对齐——`service_exec` 的三分支判据依赖它）。
3. **G6（`dnstest` 退役）本棒只登记、不删**：设计 §2.6-G6 建议「登记退役 + 从 CLI 用法面移除」，但

## 3. 红线 / 敏感面 + 一处**真回归**（如实记录）

### 3.1 真回归：中继注册腿回执被静默忽略（**C4① 引入，C4③ 修复**）

- **现象**：`quic-island-e2e.sh` 的 S2b 红——`island.rx_ignored=0` + 出口 `⚠️ 中继 … 30s 未确认注册`。

- **复验**：`quic-island-e2e.sh 1` **rc=0（5/5）**，`rx_ignored=4`（与 M1 记录一致）。
