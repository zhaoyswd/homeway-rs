# R5 评审记录（两道门）

## 第一道门：技术评审（开工前，2026-10-03）

- **渠道**：`dsh --profile headless` 外部评审（reviewer skill 流程；轮次目录
  `/tmp/dsh-review/r5d.x6MGti`，prompt/output 存档）。
- **对象**：`docs/reviews/R5-design.md` v1（未提交时点评审；评审者同时看到了工作区
  未提交的低-4/M24/enum Auth/M23 改动并据实登记——见 ②-6）。
- **实证手段**：三路独立取证（tier 词表 manifest/ledger 逐行对账；`crates/homeway-core`
  全部网络可达解析入口逐一核可达性与可见性；baseline 621fe0e 的 Go 真源逐函数回读
  ——relay cli/assoc、transport endpointcache、host_cli、speedtest engine/cli、
  upnp/publicendpoint/serve、dns server、files server）+ 既有 4 个 local-*.sh 端口
  纪律比对 + fixtures/SHA256SUMS 实跑校验。
- **结论**：**7 高 / 12 中 / 7 低**。骨架成立（六链路自洽、端口不冲突、隔离纪律同款、
  判据编号可溯、token dead-direct 测试缝可行性确认）；但 7 项高危直接卡死开工：
  - ①-1 Go relay 无 `--no-hints`（cli.go:32-35 flag 仅 state/listen/advertise；hint
    无条件双向递送 assoc.go:104-105）⇒ L2/L6 驻留判据无确定性钉法，且「翻直连=真 bug」
    的处置错误（hint→盲打→任意源采纳是设计内建自愈）；
  - ①-2 段级隔离缺失：base 段学到的直连端点落盘 endpoint cache（TTL 7 天、并入 direct
    候选），relay 段复用即复活 ⇒ via=relay 假 FAIL/PASS；
  - ②-1 一半 fuzz 目标函数 private（FrameReader/parse_report/files Stream::read_frame/
    probe decode_response/dnsproxy respond），两轨都调不到——需纯解析抽取前置步；
  - ②-2 漏 9 类网络可达解析面（UPnP/SSDP 全链【R3-H4 远程 panic 前科面】、speedtest
    服务端 parse_request 仍裸 split(',')、files 服务端、verify_reg、Ipv4View::parse、
    decode_hint_payload、probe 响应、DNS TCP 2B 分帧、WG 报文分派）；
  - ③-1 Rust 无独立 speedtest 动词（一轮=一个 connect 进程冷启动），轮次口径两侧不可比；
  - G-1 M11 的 UPnP 口径与 Go 事实相反（Go 无 per-SOAP 5s——5s 只在 M-SEARCH；SOAP 走
    40s 总 ctx、缩租独立 8s ctx）；
  - G-7 词表门「恰等」口径 3/5 必红（speedtest-reason 差 bridge_* 两值系 App bridge 面
    无生产者的合理缺席；portfwd Rust 侧无常量只有 println 字面量；files-proto 不在
    tier manifest 16 单元内、tier 侧本就排除）。
- **中危要点**：①-3 R10 分钟统计节拍 vs 25/40s 等待假 FAIL；①-4 未传 `--files-root`
  落 $HOME 且跨轮同名残留可假 PASS；①-5 echo 进程清理/矩阵锁/pgrep 口径；①-6 多 peer
  段 --hold 时序；①-7 判据死角无未纳入声明（DNS/E12/files busy/portfwd）；①-8
  Rust exit→Go relay 控制面首次方向未登记；②-3 panic-only oracle 抓不到 R2 类静默
  误解析（需分块等价/往返一致/夹具期望三类断言）；②-4 cargo-fuzz 落地细节
  （toolchain/exclude/patch/未安装）；②-5 corpus 种子提取方式；③-2 E13 用时不是尾
  延迟（p99(n=20)=max、计时源不同侧）；③-3 无预登记阈值不可 falsify；③-4 交替驻留
  形态未定义；③-5 RSS 峰值事后采样取不到；G-2 M3 口径缺口（同步逐消息/64/30s/256/
  TCP 不截断/复用上游 ID 改写面）+ 无判据；G-3 files server 并发闸 MAX_CONNS=16 零
  引用未实装（常量恰等会假绿）；G-8 vocab 正则提取三种形态+诱饵字面量（建议编译期
  vocab_dump）；G-9 faces 过滤口径；G-10 CI 缺 release 构建/fuzz exclude；G-11
  SHA256SUMS 47-50 行前缀已坏且 CI 无 shasum -c；G-13 拆步含已完成项；G-14 风险表
  缺 9 类退出口。
- **确认面（看过没发现问题）**：端口分段、隔离纪律、防串扰 1/3/4 道、六链路定义、
  token dead-direct 可行性（crc4 无密钥重算即过）、判据行措辞溯源、双轨 fuzz 思路、
  A/B 构建口径与参数同构、200pps 同值锚、§6 定位、CI 退出码、commit 粒度。
