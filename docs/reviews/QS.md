## 1. S1′：**本批不新增令牌桶**，改用仓内既有出口侧字节令牌桶（偏离任务书 S1 字面设计，**开工前登记**）

**偏离结论**：不按字面在 `crates/homeway-quic/src/exit/**` 的下行 DATAGRAM 注入点新增第二个令牌桶；
实验旋钮 = **既有** `Interceptor::pump()` 尾的字节令牌桶（`TxShape`）：

| 面 | 既有形态 | 出处 |
|---|---|---|
| 速率 | env `HOMEWAY_TX_RATE_MBPS`（**MiB/s**，`n × 1.048576e6 B/s`）/ config `[serve.tx_shape] rate_mbps` | `homeway-core/src/server/intercept/mod.rs:422` `tx_shape_resolve` |
| 突发 | env `HOMEWAY_TX_BURST_KB`（KiB，缺省 256）/ config `burst_kb`；桶容量 = 单拍放行上界（同值） | 同上 + `shape_slice`（:477） |
| 逃生口 | `HOMEWAY_TX_SHAPING=off`（值匹配） | 同上 |
| 默认 | **开**，rate=**200 MiB/s** / burst=**256 KiB** ⇒ 即本批「0 档/现状」 | `TX_SHAPE_RATE`/`TX_SHAPE_BURST`（:356/:362） |
| 生效值读回 | 启动行 `intercept: 发送整形=开（rate=…MiB/s burst=…KiB；…）` | 实测例：`rate=33MiB/s burst=256KiB` |
| 计数行 | 5s 行 `intercept: 整形观测 滞留=…包/…KB 峰值=…包/…KB 窗释=…(均…包/拍)` | `cc_stats_line`（:1904） |
| 超限策略 | **滞留 FIFO（有界）+ 下拍续传**：TCP 面**恒不丢**（队列深度由 Σcwnd 自然钳制）；非 TCP 并入超 4 MiB（`TX_DEFER_MAX_BYTES` = 16×burst）才丢新 + `shape_drop` 计数 | `tx_shape_release`（:1802）/ `filter_defer`（:1782） |
| 单测 | 桶算法/边界/保序/极小 burst 直通 = `shape_slice_budget_and_continuation`；参数解析表 = `tx_shape_resolve_config_table`；关档等价 = `pump_hold_defers_without_double_accounting` / `wait_hint_states`（`tx_shape=None` 恒直通） | `homeway-core` 单测（本批 `cargo test --workspace` 全绿复跑） |

**理由（四条，逐条带证据；任务书 §1「有更优设计要在回报里说明理由」）**：

1. **覆盖等价（零新增覆盖）**：出口侧 DATAGRAM 的**唯一**生产写入点 = `engine.rs:1647` 的 `route_out`，
   其入参 = `intercept.pump()` 的返回（`engine.rs:1387`）——**即已过令牌桶的释放集**。
   在 QUIC 注入点再挂一个桶，相对既有桶**不覆盖任何新增字节**（STREAM 面不是 DATAGRAM；plain 面不是设备流量）。
2. **语义更安全**：既有桶对 TCP 面恒不丢包、队深自然有界（≤ Σcwnd）；注入点新桶要么无自然上界
   （缓冲账不可封、与 8192 条出站队列叠加），要么丢包——后者正是仓内 R8-3 已裁定的「整形器丢包 = 伪修复禁区」
   （`docs/reviews/R8.md` §九）。真机数据也支持：本批整形档滞留在稳态**≈0**（见 §3），零排队延迟代价。
3. **红线**：`crates/homeway-core/src/server/intercept/**` 属本批红线（任务书 §2「不动」）⇒ 既有机制只能**原样用**，
   其观测缺口（**非法 env 值静默回落**，doc 注释自认「非法值静默回落默认」）本批**如实登记、不修**。
4. **零产品改动 = 最强形态「默认关/零风险」**：不设 env ⇒ 一个字节不变（收口后 `target/release/homeway-cli`
   与批前同 sha256 前 16 = `e4a5fc66f48d1bfc`）；无新队列/新定时器/新内存账。

**代价（如实）**：既有桶的速率语义是「**削峰不平率**」（R8.md §九：「R 的职责 = 团块钳制，不是速率限制」），
故本批测的是**该桶的下限方向**（把 R 压到空口锚附近），不是「注入点精确控速」；两者在**本条链路上**（§1-1 的覆盖等价）
行为面相同。若主会话/用户仍要 QUIC 注入点的**独立**旋钮，须先回答「与既有桶的关系」（串联/取代/双旋钮语义）。

## 5. 结论（本批）

1. **能不能把 T2 抬到 ≥0.95×？**——**本会话不可判**：P33/P41 对 P0 的同会话比值 1.131×/1.052× 落在
   逐轮噪声（1.71× 极差 + 会话单调退化）内；且本会话**未复现** M6.7 的强丢形态（P0 峰值 1.06× 锚 vs M6.7
   的 1.05–1.32×、P0 丢轮 2/8 vs M6.7 的逐轮 lost 64–79）。**绝对档登记**：P0 热中位 15.09 MB/s（同会话），
   与 §9.20.11/§9.20.12 的 cubic 带（19.7–20.1 MB/s，跨会话）不可互引。
2. **代价**：速率档下**稳态零排队**（滞留≈0）⇒ 无延迟/内存/体积代价（**零代码改动**）；
   burst 档（未测）预计有代价（R8-3 梯度）。
3. **留/不留**：**不改默认档**（默认 200 MiB/s 一个字节不变）；既有旋钮 `HOMEWAY_TX_RATE_MBPS`/`_BURST_KB`
   已具「可调 + 可观测 + 可退出」，**本批不新增旋钮、不新增机制**。若用户要产品面「按带宽整形」，
   下一批的动作 = 调**既有** `TX_SHAPE_RATE` 默认值（含 burst 面），本批数据支持「速率档 0.8–1.0× 锚**无害**」，
   但不支持「能补 11%」（本会话不可分）。
4. **下一个该试什么**（按本批数据的排序）：①**burst 档**（`HOMEWAY_TX_BURST_KB=32~64` + rate 0.8× 锚）——
   本批唯一未消掉的丢包面是**启动瞬态团块**（首 RTT 200–370 包，恰 = 256 KiB 缺省 burst），缩 burst 是对症臂；
   ②在**重丢会话**（M6.7 形态：P0 峰值 ≥1.1× 锚、逐轮 lost≥60）复跑 P33/P41——本批的「零增益」结论受限于
   会话未进入该形态；③若仍要打那 11%，靶子应回到**非速率面**（如岛侧回程队列 2048 包的丢面、内层 MTU）。

## 8. 方法学注记与如实登记（防后人误读）

1. **每轮 = 一次出口重启换档**（env 是进程级）⇒ 每轮都是**新外层 QUIC 连接**（`conn_id` 递增、cwnd 从
   `initial_window=12000` 起）+ **新内层 TCP 连接**（浏览器逐轮开新 URL）。本批「热」= App/隧道**进程**常驻
   （不 force-stop），**不是**连接常驻；「冷」= 前述 + force-stop + 30s 空闲 + 重注入。三档同规程 ⇒ 可比值同质。
2. **会话漂移**：同档 P0 从 11.78 s（20:07）漂到 20.15 s（20:43）——**逐轮极差 1.71×**。判决只用**时间近邻的
   同会话比值**；跨会话绝对值（含 §9.20.11 的 20.14 MB/s 与 0.95× 目标带）**只登记不判**。
3. **两轮 MISS 作废**（labels `P0h06`/`P41h03`）：浏览器侧未起下载（预热失败 + 无下载框），非出口/隧道故障
   （设备内核 `InSegs` ≈0 判死）。作废口径已在预登记内；对应点数以补齐轮次满足「每点 ≥3 热轮」。
4. **临时插桩的一处笔误**（不粉饰）：`qs[stat]` 行里的 `pkt_s` 字段打印的是 **`udp_tx` 累计值 ÷ dt**，不是
   逐秒增量 ⇒ **该字段本身无意义**；本记录引用的「逐秒包率」一律由**相邻两行 `udp_tx` 差**重算（原始累计量在案）。
5. **设备 `wlan0` 字节面未取到**（`/proc/net/dev` 解析失败，读数恒 0）⇒ 该面登记为**未取**，改用
   设备内核 `Tcp InSegs/RetransSegs` + `Udp RcvbufErrors` + 出口 `udp_tx` 三面互证。
6. **burst 档未做**（时间预算）——本批数据把它指为第一优先（§5-4①）。
7. **T6 的设备 PID 变更**：冷档/部分热档 App 重启换 pid ⇒ 仅取**轮内**同 pid 的 CPU 差（`rounds.tsv` 第 10/11 列）；
   P0h06 作废轮不参与 T6 中位。
