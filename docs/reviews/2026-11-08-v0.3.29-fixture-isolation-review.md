# v0.3.29 relay_admission_e2e 夹具隔离独立评审

日期：2026-11-08。范围仅 `crates/homeway-core/tests/relay_admission_e2e.rs` 的临时目录分配，不评为运输协议修复。

## 技术门：通过

旧 PID + SystemTime 纳秒表示不能保证唯一。独立 Rust 实验 `/tmp/homeway-wallclock-uniqueness-7knngc99` 的四线程 10000 轮中 1238 轮重复，且纳秒值均为微秒整倍数。源码的共享路径会使 state.key 的创建/截断互相干扰，属于必须移除的测试隔离缺陷；这不能证明公开 CI 首次 UDP NoCandidate 的唯一根因。

新方案使用进程内 Relaxed AtomicU64 分配候选名，再以 `DirBuilder::create` 原子占有；AlreadyExists 只更换候选，既有目录/文件不会被复用或截断。Unix 请求 0700，非 Unix 保留可编译的原子 create_dir 路径。跨进程同 PID 历史残留由原子占有兜底，不依赖墙钟或随机概率。没有串行化四个业务用例，也没有延长预算。

## 代码门：通过

独立核对完整 diff：只有移除 SystemTime import、新增上述 helper、fixture 调用替换。四个业务用例、洪泛流量、断言和时间窗逐字未变；没有修改产品 State、wire 或行为判据。Rust 使用 std 原子和类型化 io::ErrorKind 分支，无新增依赖或逐行移植迹象。

验证实物 `/tmp/homeway-nocandidate-causal.NQISzw/`：已核当前源码 SHA 与 `fixed-rounds.json` 一致（0b2e54614286413714c123a52454e3f91083ff37ba20b1e25e03cd950b5abf0d）；三个 `fixed-full-{1,2,3}.log/.exit` 均真实 4/0、exit 0；固定二进制 SHA ad3eb9fdcf95708c1cdebfb97c3d3105b4642b26fafa01e16508fdf001b67aae。`fixed-conflict.log/.exit` 对 actual helper 预占 seq0 sentinel、四线程 1024 次预留，1025 目录唯一、0700、sentinel 未动，exit 0；定向 clippy -D warnings 的 `fixed-clippy.exit` 为 0。未把有限次数通过表述为消除所有 NoCandidate。

## 失败披露与放行边界

公开 v0.3.28 原失败是 UDP-only 首次 Connect NoCandidate；独立未改运输源码的固定二进制三轮为 0/101/0，其中失败轮是另两条 Connect NoCandidate，UDP 用例反而通过；后续诊断另见 state.key 长度 0。三种签名保持区分。修复一个确定存在的 fixture 名称碰撞风险，允许推送 v0.3.29 让正式 CI 验证；正式 Release、controller 两门及生产激活仍是独立必要门。本评审不授权以本地件部署，不重指 v0.3.28 tag。
