  的影响已被 M0/§9.1 登记）；**门槛（≤96K）在两种口径下都过**，且**不依赖**那条无原始证据链的 37.6K。

**(d) 32 设备稳态（§9.1-2 修订门槛 ≤ +3.1 MiB）**

- 直测：`N=32 → 2704K`，基线（N=1）1232K ⇒ **增量 1472K = 1.44 MiB ≤ 3.1 MiB ✓**
- 用保守斜率复核：三点口径 84K × 32 = 2688K = **2.63 MiB** ✓；五点 80K × 32 = 2560K = 2.50 MiB ✓
  （三路都过 ⇒ 判据不依赖拟合口径的选择）

**(e) 负载态门槛（§9.1-4：32 连接 + 持续流量 ⇒ 增量 ≤ 64 MiB + 自有队列上限）**

| 档 | 空转 | 负载态中位 | 增量 | 判据 |
|---|---|---|---|---|
| N=32 × 200pps × 1280B（≈65 Mbps 总入流；客户端正常排空） | 2816K | **3520K** | **+704K** | ≤65536K ✓（大余量） |
| 同上但客户端 **不读回程**（`--no-read`：顶满服务端发送缓冲的最坏面） | 2752K | **3472K** | **+720K** | ≤65536K ✓（大余量） |

- **如实说明（勿当"缓冲已测透"）**：两条读数的增量都 ≪ 64 MiB，因为 **quinn 的 datagram
  收发缓冲是按需增长**（`VecDeque` 惰性；§6.3 的主张）——应用侧预检（`datagram_send_buffer_space()`）
  使缓冲最多只比在飞数据多一点。64 MiB 是**解析上界**（32 × (1 MiB send + 1 MiB recv)），
  在回环上不可达（路径恒快于应用）。**本档测到的是「惰性 + 预检纪律的实测面」**，
  与分析上界一起构成结论；"把缓冲真顶满"需要出口侧限速（中继闸不具备该形态）——**登记为 M6/真机面**。

## 2. S5-2 端到端 A/B（本地代理；**产品路径**＝`ClientCore` 世代 + TUN socketpair + 合成 UDP 流）

拓扑：`m1-ab`（产品路径客户端）→ 直连（LAN QUIC/WG 端点）→ 本地 Rust 出口 → `intercept` transit →
本机回显（**放大 1:1，回包满尺寸 1252B 载荷 ⇒ 内层 1280B**）；两臂**同刻交替**（轮序奇偶反转）。

**(a) 同报头档（rate=3000pps / window=32；`/tmp/m1s5-res/e2e/ab-direct-*-r*.log`）**

| 轮 | quic 下行 | quic 丢包 | wg 下行 | wg 丢包 |
|---|---|---|---|---|
| r1 | **30.72 Mbps** | 0.00% | **30.72 Mbps** | 0.00% |
| r2 | **30.72 Mbps** | 0.00% | **30.72 Mbps** | 0.00% |
| r3 | **30.72 Mbps** | 0.00% | 19.51 Mbps | 0.21% |

- 判据「**无数量级回退**」⇒ **成立**：quic 三轮全部满额（30.72 Mbps = 3000pps × 1280B × 8）；
  wg 三轮 30.72 / 30.72 / 19.51（r3 那一格是单轮机器噪声，损失 0.21% 且下行 19.51 Mbps 仍是同量级）。
- 两臂 `link.via` 复核：quic = `direct`（`ep=192.168.3.12:42653`）、wg = `direct`（`ep=192.168.3.12:42652`）
  ⇒ **同路径**（quic 档用 `--force-direct` 把 token 的中继端点改死，否则本地回环下赛跑可能被中继抢先——
  首跑实测踩过，见 §5 L3）。

**(b) 容量档（rate=0 / window=64 = 只受在飞窗约束；`ab-cap-*.log`）**

| 轮 | quic 下行 | wg 下行 | quic/wg |
|---|---|---|---|
| r1 | **162.42 Mbps** | 131.28 Mbps | 1.24× |
| r2 | **143.25 Mbps** | 126.68 Mbps | 1.13× |
| r3 | **157.05 Mbps** | 124.64 Mbps | 1.26× |

- **本机回环口径**（合成 UDP、无 TCP 反馈、单机同进程拓扑）⇒ **不是 PERF-AB 真机数**（§8 的标注照搬）。
- 结论：本地合成面上 **QUIC 档不低于 WG 档**（1.13–1.26×，与 M0「每包 CPU 0.87×」同向）。

## 3. S5-3 中继预算与迁移（§7.2 B1/B2/B3/B5）

拓扑：本地 Rust 中继（`127.0.0.1:42782`，`--rate-limit` 缺省 200pps/源）+ 本地 Rust 出口（挂中继腿）。
**中继代码零改动**（红线）——全部读数由客户端/出口侧仪器取得。

### 3.1 B1 包尺寸（**读字节计数**，不用 lo0 分片断言）

`tools/quic-probe` 的 socket 级计数（`/tmp/m1s5-res/e2e/probe-size-readings.txt`）：

| 方向 | 实测（本切片） | 设计理论值 | 结论 |
|---|---|---|---|
| **上行线上**（`sock.tx_max`，客户端发 1362B 内层包 = 连接 mds） | **1411 B** | **1411 B**（QUIC 包 1400 + 信封 11） | **逐字节命中** ✓ |
| **下行线上**（`sock.rx_max`，回显面回满尺寸） | **1322 B** | 1402 B（QUIC 包 1400 + 信封 2） | **不可达**，机制见下 |
| 产品形态内层 MTU 1280 时（探针 1280B 档实测） | 上行 **1331 B** / 下行 **1322 B** | — | 1280+40+11 / 1280+40+2 |
| 中继 `丢弃` 计数 | 尺寸用例期间**不增** | 不增 | ✓ |

- **为什么下行是 1322 而不是 1402（实质发现，须写进 M1 报告）**：出口的 L3 出口面按
  **内层 MTU（1280）**构造回程内层包 ⇒ QUIC 包 ≈1320 B（永远吃不满 1400 的 QUIC MTU）⇒ 线上 = 1322。
  1402 只有在「内层包 = 1362B」时才可能出现，而 1362 已**超过内层 MTU**——上行能到 1411 是因为
  探针（非产品面）可以发 1362B 内层包；**岛的产品面按 `mtu=1280` 检包**，其上行线上上界 = **1331 B**。
  ⇒ 设计 §5.1 的「内层 1280 / 线上 1411/1402」是**算术上界**；产品形态的线上区间是
  **上行 ≤1331 B、下行 ≤1322 B**（信封 +11/+2 逐字节验证成立）。

### 3.2 B2 上行 200pps 闸（**含同桶形态说明**）

探针 `push` 灌包（1280B/个），两次运行（`/tmp/m1s5-res/e2e/probe-rate-sep*.log`），
中继侧读 `中继统计：… 转发 上 X / 下 Y 包｜丢弃 Z` 的**两条相邻 60s 行做差**：

| 运行 | 探针源 | 报头 | 客户端实发（QUIC 层） | 中继转发上（60s 窗） | 中继丢弃 | `congestion_events` / `lost_packets` |
|---|---|---|---|---|---|---|
| D2 | `192.168.3.12`（**独立桶**） | 400pps × 75s | 138 pps（10338 包） | **117 pps**（7000/60s） | +885 | **45 / 1114** |
| D2b | `192.168.3.12`（独立桶） | 250pps × 80s | 137 pps（10979 包） | **106 pps**（6352/60s） | +759 | **47 / 1206** |
| D3 | `127.0.0.1`（**与出口同桶**） | 400pps × 65s | 150 pps（9771 包） | **53 pps**（3203/60s，窗覆盖部分运行） | +1630→3209 | **40 / 993** |

- **闸的真实形态（两条，都必须写清）**：
  1. 限流是 `rate_ok(src.ip())` 的 **1 秒定窗计数**（`relay/mod.rs:1576`，按**源 IP**不分端口）
     ⇒ **突发会被裁**：QUIC 的 cwnd 突发（数十包同拍）在窗内先到 200 上限，其余被静默丢；
  2. 被丢的包对 QUIC **不可区分于拥塞** ⇒ CUBIC 退避（Q-L 闭环）⇒ 可持续速率稳定在
     **~106–150 pps**，**低于** 200pps 的准入上限（这正是设计 Q-L/Q-B 预判的机制，
     本切片给出量化：`cong_events` 40–47、`lost_packets` 993–1206 均在**触闸运行内**）。
- **同桶形态（r12 专4-5）**：本地回环下探针与出口同为 `127.0.0.1` 时共用一个 200pps 桶
  （D3 的转发率被压到 53pps）⇒ 报告与本表**一律标注探针源地址**；`127.0.0.2` 在本机不可绑
  （`EADDRNOTAVAIL`，见 §5 L4），独立桶用 **本机 LAN 地址**取得。
- 绝对数字只登记、标注**本机回环口径不可比**（§12-④ 的拍板口径）。
