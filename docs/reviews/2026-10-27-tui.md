# homeway TUI（2026-10-27）

## 范围与技术设计

用户授权在 `tui` 分支实现 `homeway tui`。参考 [herdr](https://github.com/herdrdev/herdr)
的主机/会话切换、原终端内容与状态可见交互；采用 homeway 原有 token、daemon 与 term
服务，不引入 SSH 或另一套会话服务。现役进程和正式 state 不用于测试。

界面使用仅 CLI 非 Windows 目标依赖 ratatui 0.30.2 / crossterm 0.29；Rust 工具链 1.99
满足依赖要求。core/capi 不引入 TUI 依赖。布局为左上主机、左下会话、右侧 VT 终端，
侧栏标题含添加操作，深浅主题单独存储在 state 内。颜色之外同时提供中文状态文字。

所有控制面调用通过有界后台命令/事件通道，主事件循环仅轮询本地事件，离线主机查询
有截止时间。主机列表、角色、代理均使用已有控制面操作。启动角色后获取 token，代理
启动后获取实际 SOCKS 监听地址，复制完成才提示成功；系统剪贴板不可用时显式提示
OSC52 请求或失败，token 不进入常驻界面或日志。

会话列表消费 term LIST 的 title/agent/state/cwd，兼容扩展agentLabel保留pi等身份；创建使用 CREATE，关闭使用
KILL。选中会话开一条 raw attach，输出仅交给 SessionVt 解析后按 cell 绘制，防止输出
ANSI 覆盖侧栏；不向外层终端透传控制序列。按键使用既有 keyenc 与当前 VT 模式。
切换主机/会话立即销毁旧腿，并以 generation 过滤过期数据。离线禁输入，退出只分离。

默认键盘输入发送会话；Ctrl+B 前缀用于导航、添加、主题和退出，侧栏F6切换焦点、F10退出，终端内功能键透传。
侧栏焦点使用方向键，右键菜单支持 Esc/方向键/Enter。鼠标命中以同一绘制几何和列表
滚动偏移计算，窄屏显示尺寸引导，弹窗和菜单裁在屏内。宽字符按 VT cell.width/skip
处理。终端设置由 RAII 还原，panic hook 和信号退出同样关闭鼠标/raw/备用屏。

### 补充定案

- **本地所有权**：非 Windows 统一进程启动一个只监听 UDS 的进程级 TermService；
  `local-term.sock` 与开启出口时的 QUIC term intake/`serve/term.sock` 借用同一注册表。
  serve stop/restart 不结束本地会话，退出统一进程才 close 服务。监听失败记录日志并降级，
  不妨碍原有出口/中继启动。`HOMEWAY_TERM=off` 不启动，TUI 显示本地不可用错误。
  TUI 和 term CLI 本地均优先新 UDS，缺失时兼容既有出口 UDS；不重启旧守护。
- **回放与应答**：ATTACHED 后只重建屏态，REPLAY_DONE 前禁止输入及历史查询应答；之后
  SessionVt 收集应答回投 DATA。多腿的唯一应答者沿用服务端 `response_owner` +
  `pure_terminal_reply` 校验，非 active raw 回答被丢弃。同步输出超时每拍 flush。
- **稳定身份**：列表返回携带 target+请求 epoch，新建结果携带导航 epoch；以主机ID和
  会话name保选，重排不改变目标。attach独立generation、销旧连接并清待发输入；失败
  保留屏态禁输入，用户重新选择恢复，不另造自动重连阶梯。
- **有界工作**：会话查询独立latest-only单槽（进行中的旧查询有绝对截止，新选择覆盖
  待处理项），不阻塞角色/创建操作；host.add 20s、角色操作10s、term开流/握手共用
  10s绝对截止，列表短3s。队列满明示忙，resize仅成功入队后确认，同尺寸可重试；输入
  在2MiB有界队列内按16帧/拍调度，大粘贴先作整体预算检查，不能半截静默丢弃。
- **操作结果**：提交、复制、刷新各自报告；启动成功但取token/刷新失败不能抹掉已成功
  事实。删除主机不会KILL远程会话，KILL失败保留选择以便重试。菜单已是用户明确要求的
  操作入口，不再额外要求权限/名称确认（主会话明确裁定）；文案区分关闭会话与删除主机。
- **识别兼容**：LIST additive可选`agentLabel`来自既有manifest进程匹配采样（含pi），
  不改变固定agent枚举/STATE帧；TUI优先label，缺失回退原agent。进程退出清label，
  projectname取既有cwd末段，缺测留空，状态未知明确显示“未知”。
- **终端输入**：外层请求kitty消歧/事件类型扩展并在退出pop，未支持终端忽略；已提交
  Unicode文本由crossterm送入keyenc，Release/Repeat按当前VT模式编码。Ctrl+B为管理前缀，
  Ctrl+B Ctrl+B发送字面键，终端F6/F10照发，侧栏便利键保留。切焦点发送现有focus编码。
  首版显示当前viewport；终端应用启鼠标时转发相对网格事件，暂不额外实现本地历史浏览器。
- **主题与剪贴板**：主题文件`<state>/tui-theme`以rename原子保存，损坏回深色，保存失败
  不影响当前切换。默认fg/bg随主题，应用显式RGB/ANSI色保留。系统复制成功基于helper退出
  状态，OSC52只提示“已请求”；SSH优先终端请求。远端程序OSC52读写不自动触达系统剪贴板。
  helper stdin使用0600随机文件，创建即unlink再写入，不使用可能SIGPIPE的pipe；2s超时
  kill+wait，stdout/stderr为null；token不写日志/常驻屏幕。
- **初始化与退出**：阶段guard在安装第一个信号前已构造，任一步失败均Drop还原；
  SIGINT/SIGTERM/SIGHUP仅设置atomic退出标记，panic hook恢复终端并使主循环停止。
  后台有取消位与关闭句柄；退出不等待可能仍在预算内的网络请求，不阻塞界面收尾。
  `--help`不启动服务，非TTY拒绝；Windows明确报不支持。默认state与既有CLI一致，
  首次进入可按原dial-control-spawn契约拉起统一进程（其角色按既有config期望态运行）。
